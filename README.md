# ROOFRUNNER

노을, 항구, 네온, 새벽의 로우폴리 도시를 자유롭게 달리는 3인칭 파쿠르 타임 어택입니다. **필수 옥상 A–H 여덟 곳을 원하는 순서로 모두 방문**하면 마지막 착지 순간의 시간이 기록됩니다.

## 실행

Node.js 22.12 이상과 WebGL을 지원하는 PC 브라우저가 필요합니다. 이 디렉터리에서 실행하세요.

```sh
npm install
npm run dev
```

```sh
npm test          # 방문 규칙, 모든 링크 주행·복귀 가능성, 벽점프·슬라이딩 검증
npm run build    # dist/에 정적 배포 파일 생성
npm run preview  # 빌드 결과 실행
```

## 게임 규칙

- 중앙 옥상에서 카운트다운 후 출발합니다.
- 도시마다 17–21개의 옥상이 서로 다른 모양으로 이어져 있습니다(아래 표). 옥상 가장자리의 민트색 화살표는 오갈 수 있는 길, 주황색 화살표는 뛰어내리기만 되는 길입니다.
- A–H로 표시된 8곳만 필수 목표입니다. 글자는 식별자이며 방문 순서가 아닙니다.
- 필수 옥상의 바닥에 착지하면 방문이 인정됩니다. 벽 접촉, 공중 통과, 옆 건물이나 배관 위 착지는 인정되지 않습니다.
- 일반 옥상은 지름길이나 연결 경로입니다. 정상 착지한 옥상으로 복귀 위치가 갱신됩니다.
- 재방문은 중복 집계하지 않습니다. 마지막 목표 착지 즉시 시간이 멈추며 별도의 도착선으로 갈 필요가 없습니다.
- 추락하거나 R로 복귀해도 방문한 목표와 시간은 유지됩니다. Esc 또는 창 전환으로 일시정지하면 시간도 멈춥니다.
- T로 재시작하면 시간과 방문 목록이 모두 초기화됩니다.
- 결과 화면에 기록과 실제 방문 순서가 표시됩니다.

## 조작과 미니맵

| 조작 | 동작 |
| --- | --- |
| WASD / 방향키 | 자동 질주 |
| Space | 점프 |
| 벽에서 Space를 떼었다 다시 누르기 | 반대쪽으로 도약하며 전진 속도 유지 |
| Shift | 슬라이딩 — 낮은 설비 아래 통과 |
| Shift → Space | 슬라이딩 속도를 유지하며 점프 |
| R | 마지막 착지 옥상에 복귀 |
| T | 현재 도시 처음부터 재시작 |
| Esc | 일시정지 / 계속 달리기 |

카메라는 실제 이동 방향을 360도로 따라갑니다. 마우스로 시점을 조작하지 않습니다. 방향 키 조합을 새로 누르는 순간의 화면 방향을 기준으로 이동하며, 같은 키를 계속 누르면 카메라 회전 때문에 달리는 방향이 휘지 않습니다. Ctrl은 게임 조작에 사용하지 않습니다.

오른쪽 미니맵은 북쪽이 위입니다. 주황색은 미방문 필수 옥상, 민트색은 방문한 옥상, 흰색 화살표는 캐릭터입니다. 목표를 클릭하면 해당 옥상이 강조됩니다. 선택한 목표와 관계없이 어느 필수 옥상이든 방문할 수 있습니다.

## 도시와 장애물

네 도시는 색만 다른 게 아니라 **배치 형태**가 다릅니다.

| 도시 | 형태 | 옥상 · 크기 · 높이 | 벽 · 슬라이딩 | 특징 |
| --- | --- | --- | --- | --- |
| 선셋 디스트릭트 | 원형 광장 | 21개 · 112×152m · 19–25m | 2 · 3 | 나무가 둘러싼 광장 위로 옥상이 고리를 이룹니다. 네 개의 육교로 중앙을 가로지르거나 고리를 어느 방향으로든 돌 수 있고, 두 종탑 전망대는 벽을 차야 올라갑니다. |
| 하버 라인 | 두 층의 부두 | 17개 · 200×137m · 14–22m | 3 · 4 | 동서로 긴 창고 거리(위층)와 바다 위 방파제·부두 셋(아래층). 위에서 부두로 뛰어내리기는 쉽고, 올라오려면 창고 외벽을 차야 합니다. 동쪽 끝 바다에 등대가 서 있습니다. |
| 네온 하이츠 | 나선 고층 | 20개 · 114×120m · 23–42m | 3 · 2 | 좁은 옥상이 빈 중심(홀로그램 마스트)을 돌며 벽을 차고 올라갑니다. 꼭대기 왕관에서는 출발점으로 곧장 떨어지고, 바깥 골목들은 낙하로만 들어가 긴 계단길로 돌아옵니다. |
| 새벽 언덕 | 비탈 계단 | 18개 · 136×131m · 18–39m | 2 · 3 | 북서 꼭대기에서 남동 기차역까지 계단식 지형을 따라 내려갑니다. 내리막은 긴 활강 한 줄, 오르막은 좁은 계단길과 벽입니다. 주변 집들도 비탈을 따라 낮아집니다. |

설비와 랜드마크는 도시마다 유지합니다: 선셋은 물탱크·빨래 건조대·타워 크레인, 하버는 화물 상자·컨테이너·등대, 네온은 실외기·전광판·마스트, 새벽 언덕은 온실·차양·송신탑입니다.

슬라이딩 설비 아래 여유는 1.05m, 서 있는 키는 1.7m, 슬라이딩 높이는 0.85m입니다. 설비는 동서·남북 어느 방향 통로에도 놓이고, 구조물 옆으로 돌아가는 길도 열려 있으며, 양방향으로 접근할 때 안내가 표시됩니다. 설비가 있는 옥상은 이웃보다 2m 높은 설비층이라서 뛰어 올라오면 설비 앞에 착지합니다(Shift를 누른 채 뛰면 착지와 동시에 미끄러집니다).

벽 구간은 주변의 높은 건물 외벽을 활용하며, 동서남북 어느 방향으로도 놓입니다. 외벽을 스치며 뛰면 낙하가 느려지고, Space를 다시 눌러 벽을 차면 높은 옥상으로 올라갑니다. 이동 속도는 19.5m/s, 슬라이딩은 최대 25m/s이며 모든 도시에서 같은 물리 값을 사용합니다.

## 기록

도시별 상위 10개 개인 기록을 localStorage에 저장합니다. 현재 온라인 공용 랭킹이나 계정 서버는 연결되어 있지 않습니다. 저장 공간을 사용할 수 없으면 현재 세션에서만 기록을 유지합니다.

기록 키는 `roofrunner-records-v5-<도시 id>`입니다. 도시 배치가 바뀌어 v4 기록과는 비교할 수 없어서 키를 올렸습니다. 예전 v1–v4 데이터는 삭제하지 않으며 새 기록과 섞지 않습니다. 선택한 도시는 기존 `roofrunner-map` 키에 기억됩니다.

## 구현과 검증

Three.js와 Vite를 사용합니다. 외부 3D 에셋 없이 코드로 도시와 캐릭터를 생성합니다. 정적 구조물은 재질별로 병합하고 창문은 인스턴싱합니다. 도시 변경 시 이전 도시의 리소스를 해제합니다. Google Fonts에 연결되지 않으면 시스템 글꼴을 사용합니다.

- `src/physics.js`: 도시 테마와 배치(`MAPS[].layout`), `buildDistrict()`·`buildTowers()`·`buildGates()`, 캐릭터 물리
- `src/exploration.js`: 방문 집계, 복귀 위치, 시간 및 완료 판정
- `src/main.js`: 렌더링, 자동 카메라, 미니맵, 게임 상태와 결과 UI
- `src/style.css`: 시작 화면과 게임 UI
- `tests/movement.test.js`: 네 도시의 모든 인접 옥상 연결을 양방향으로 검사, 슬라이딩·벽점프 검증
- `tests/exploration.test.js`: 자유 순서, 시간 정지, 중복·잘못된 접촉 제외, 복귀·재시작 검증
- `tests/physics.test.js`: 점프, 시간 표시, 저장 기록 검증

### 배치 수정하기

각 도시의 `layout`은 출발 옥상과, 이미 있는 옥상 옆에 새 옥상을 붙이는 단계들로 이루어집니다.

```js
{id:'ne1', from:'n', dir:'E', gap:5, w:24, d:12, dy:2, name:'빨래 건조대 골목', slide:{kind:'laundry', axis:'x'}},
{id:'perch', from:'ne', dir:'N', gap:10, w:16, d:14, dy:4, wall:{side:-1}, label:'B', name:'노을 전망대'},
{join:['nw2','n']},
```

- `dir`(N/E/S/W)·`gap`(마주 보는 가장자리 사이 빈 공간)·`off`(옆으로 이동)·`dy`(높이 차)로 위치를 정합니다. `label`을 주면 필수 옥상입니다.
- 링크 종류는 높이 차로 정해집니다. |dy|≤2는 양방향, 그보다 크면 높은 쪽에서만 내려가는 낙하, `wall`을 주면 외벽을 차고 오르고 반대로는 낙하합니다. `join`은 이미 있는 두 옥상을 잇습니다(`kind:'drop'` 또는 `wall` 가능).
- 몸이 실제로 할 수 있는 거리: 양방향은 평지 8.5m·±1m 8m·±2m 6.5m, 낙하 13m, 벽은 +4m일 때 9–12.5m·+5m일 때 9–10.5m이며 두 옥상이 일직선이어야 합니다. 마주 보는 가장자리는 6m 이상 겹쳐야 합니다. 값은 `JUMP`에 있습니다.
- 슬라이딩 설비(`slide:{kind, axis, at}`)는 `axis` 방향 통로를 막습니다. 그 옥상으로 드나드는 링크는 모두 같은 축이어야 하고, 양쪽 여유가 9m 이상이어야 합니다. `at`으로 설비를 한쪽으로 옮길 수 있습니다.

`npm test`가 모든 링크를 선언된 방향으로 실제 물리로 달려 보고, 벽 링크는 점프만으로는 안 되고 벽을 차면 되는지, 어느 옥상에서든 출발점으로 돌아올 수 있는지, 옆 건물이 옥상이나 달리는 선을 막지 않는지 검사합니다.
